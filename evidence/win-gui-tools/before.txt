Why (source, identical at 5416c67 and 5f380c3)
- CommandLineToolRunner::toolName() returns applicationDirPath() + "/vc_render_tifxyz" (and
  vc_grow_seg_from_segments, vc_tifxyz2obj, vc_obj2tifxyz_legacy, vc_objrefine, vc_grow_seg_from_seed,
  vc_merge_tifxyz, vc_merge_patch) with no ".exe".
- CommandLineToolRunner::execute() stops with "Tool executable not found or not executable: %1" unless
  QFileInfo(toolCmd).exists() && isExecutable(). QFileInfo does not add ".exe", so this is always false on Windows.
  Interactive callers (menus, context menu) get that text in a warning box; silent bridge callers get false.
- SegmentationCommandHandler::startRenderSegment (render.tifxyz), startResumeLocalGrowPatchImpl
  (vc_grow_seg_from_seed) and startAlphaCompRefineImpl (vc_objrefine) repeat the same extensionless check
  before execute(), which is the -32006 text above.
